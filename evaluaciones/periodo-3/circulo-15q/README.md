# Geometry 8 - Period III - Circle Evaluation - 15 Questions

Senior LaTeX assessment package prepared for the first Period III grade after Semana Robledista.

## Structure

- Version A: 15 open-response questions, 5 pages, 45 points.
- Version B: 15 open-response questions, 5 pages, 45 points.
- Version C: 15 open-response questions, 5 pages, 45 points.
- Teacher key for all three versions.
- Combined print master: 15 student pages.

## Scope

The assessment stays inside the current circle block and the repository's Circle Clash scope: radius, diameter, circumference/perimeter, area, and pi. It also evaluates inverse problems, scaling, real-world applications, and error analysis. Composite/shaded-area and solids content is intentionally excluded.

## Question architecture

1. Circle elements.
2. Given radius -> diameter, circumference, area.
3. Given diameter -> radius, circumference, area.
4. Exact circumference -> diameter, radius, area.
5. Exact area -> radius, diameter, circumference.
6. Decimal circumference using pi ~= 3.14.
7. Decimal area using pi ~= 3.14.
8. Compare two circles and ratios.
9. Radius scaling and effect on circumference/area.
10. Rolling-wheel distance.
11. Circular garden and fencing cost.
12. Circular floor and covering cost.
13. Real-world inverse circumference.
14. Error analysis: diameter vs radius.
15. Multi-step radius-change challenge.

## QA

All three versions were compiled from LaTeX, rendered page-by-page, checked for figure geometry and label placement, preflighted, and mathematically recalculated. Final student PDFs contain no overfull/underfull box warnings or unresolved LaTeX errors.
