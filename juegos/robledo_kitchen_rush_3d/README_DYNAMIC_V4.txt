ROBLEDO KITCHEN RUSH 3D — DYNAMIC CREW EDITION

NEW SHIFT FLOW
1. Choose 1, 2 or 3 human players.
2. Assign a role to all three crew slots. Empty human slots become bots.
3. Choose 3–5 active dishes.
4. Complete/skip the tutorial briefing.
5. Build the restaurant before opening: tables, ingredient crates and kitchen stations all cost from the starting budget.
6. Open Restaurant and run service in real time.

CAMERA
Right mouse drag = orbit
Mouse wheel = zoom
C = cycle Dynamic / Classic / Top camera
Home = reset camera
Dynamic mode follows the crew and adds a subtle gyroscope-style lean.

BUILD MODE
Left click = place selected fixture on snapped floor grid
R = rotate selected fixture
Delete = remove highlighted fixture and refund its cost
Recommended Layout = install a valid starter plan automatically

HUMAN CONTROLS
P1: WASD / E interact / Q throw / Left Shift dash
P2: Arrows / Enter interact / Slash throw / Right Shift dash
P3: IJKL / O interact / U throw / P dash
Gamepads: left stick / A interact / X throw / B dash

ROLES
Head Chef: faster stove/fryer/oven work and more burn tolerance.
Prep Specialist: faster chopping and slightly faster movement.
Service Captain: faster movement/washing and larger service tips.

The game is designed to remain fully local/offline. The Windows launcher serves the embedded Three.js build over 127.0.0.1 to avoid file:// browser restrictions.
